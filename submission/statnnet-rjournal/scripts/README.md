# R Journal submission bundle

This directory contains the article and motivation letter for
"statnnet: Regression-Style Statistical Summaries for Neural Networks Fitted
with nnet" by Andrew McInerney and Kevin Burke.

The article source, extracted R code, LaTeX source, bibliography, PDF, and web
version use the common basename `mcinerney-burke`. `RJwrapper.tex` and
`RJournal.sty` are generated by `rjtools` for the journal-formatted PDF.

## Reproduction

Install the current `statnnet` package source and the packages listed in
`reproduce.R`. From this directory, run:

```sh
Rscript scripts/reproduce.R
```

The script renders every output format declared in `mcinerney-burke.Rmd` and
fails if any expected article artifact is absent. Random initialisations in the
worked example use a fixed seed, and only converged fits are eligible for
selection.

The package source and development history are maintained at
<https://github.com/andrew-mcinerney/statnnet>. Submission should take place
only after the corresponding package release is available from CRAN.
